Contraction Check

Numerically verifying the corrected convergence theorem for adaptive world-model operators

Implements: DYNAMO: Dynamic Adaptive Neural Architecture (world model)

1The problem

Adaptive world-model architectures iterate a learned operator T(W) = (1−α)W + α·U(W). If U is not a contraction, the iteration can diverge — and the original convergence proof contained an algebraic error that masked exactly this.

2The paper

DYNAMO: Dynamic Adaptive Neural Architecture (world model) (under journal revision, 2026). Theorems about learned operators are rarely checked numerically. A wrong contraction claim (ρ=1.4 presented as <1) can survive peer review because nobody runs the 20-line verification.

3What this implements

Spectrally clip each layer to σ_max ≤ L^{1/d} so the update operator provably has Lipschitz constant <1, then measure the empirical per-step contraction rate against the predicted ρ = (1−α) + αL across spectral caps. The implementation is the paper's own contraction_check experiment, rebuilt from the corrected theorem.

The empirical contraction always lies below the predicted rho (the theorem is a valid upper bound). At L = 0.5 the bound is tight (gap 0.026) and iterates converge; as L approaches 1 the bound approaches 1 and contraction plateaus; at L = 1.05 the operator expands.

6Insights

  • The bound is tight only well inside the contraction region (L=0.5); near the boundary the empirical rate plateaus — theory is conservative where it matters.
  • Spectral normalization rescues the implementation even when the proof is wrong: constraints on weights are checkable, algebra is not.
  • A 20-line numerical check should be a required companion to every contraction claim in ML papers.
