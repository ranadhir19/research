# User guide: ghosh-research

Ten research papers, each turned into a runnable application. This guide shows how to
run, reproduce, and extend them. Everything runs on CPU with numpy, scipy and matplotlib.

## Running the demos

Each application ships a one-minute quickstart in `examples/`:

```bash
cd research
PYTHONPATH=src python examples/01_cst_quickstart.py   # ethical subset construction
PYTHONPATH=src python examples/02_cais_quickstart.py  # document-region matching
PYTHONPATH=src python examples/03_closure_quickstart.py
PYTHONPATH=src python examples/04_pinn_quickstart.py
PYTHONPATH=src python examples/05_dsai_quickstart.py
PYTHONPATH=src python examples/06_dynamo_quickstart.py
PYTHONPATH=src python examples/07_kpi_quickstart.py
PYTHONPATH=src python examples/08_bukpi_quickstart.py
PYTHONPATH=src python examples/09_memento_quickstart.py
PYTHONPATH=src python examples/10_siamese_quickstart.py
```

All ten run green in under a minute each (kpi's full experiment takes ~2 minutes; its
quickstart is fast).

## Reproducing the experiments

The numbers on the landing site and in each README come from scripts in `experiments/`:

```bash
PYTHONPATH=src python experiments/dynamo_experiment.py
```

Each script:
- uses a fixed seed (recorded at the top of `results/<slug>/results.md`),
- writes `results/<slug>/results.md` (measured tables) and `results/<slug>/charts.png` (charts).

Re-running a script should reproduce the published numbers exactly. If a number differs,
open an issue — the table, not the run, is the bug.

## Using the libraries

Every application is an importable package with a documented public API:

```python
from ghosh_research.cst import greedy_maximal_subset        # ethical subset
from ghosh_research.cais import hungarian_match             # document regions
from ghosh_research.closure import hybrid_discovery         # closure simulation
from ghosh_research.pinn import fhp_loss                    # physics-informed loss
from ghosh_research.dsai import hybrid_pricer                # option pricing
from ghosh_research.dynamo import contractive_operator       # world-model operator
from ghosh_research.kpi import metropolis_hastings, bayes_factor  # edge validation
from ghosh_research.bukpi import correlate                  # type-aware correlation
from ghosh_research.memento import PrototypeBank, refit      # retention vs plasticity
from ghosh_research.siamese import ContrastiveEncoder        # CAR/LAR verification
```

See each package's docstrings and `<slug>/README.md` for signatures and examples.
The per-project README also cites the paper it implements and notes any measured
deviations from the paper's reported figures.

## Extending an application

1. Copy the package under `src/ghosh_research/` to a new slug and rename it.
2. Add an experiment in `experiments/` that writes `results/<new>/results.md` + `charts.png`.
3. Add a quickstart in `examples/` and a `<new>/README.md` citing the paper.
4. Rebuild the site with `python3 docs/build.py`.

## Where things are

| Path | What it is |
|------|-----------|
| `src/ghosh_research/<slug>/` | library code, documented public API |
| `experiments/<slug>_experiment.py` | full experiments (source of all reported numbers) |
| `results/<slug>/results.md` | measured result tables with seeds |
| `results/<slug>/charts.png` | charts |
| `<slug>/README.md` | per-project README + paper citation |
| `examples/NN_<slug>_quickstart.py` | one-minute demos |
| `docs/index.html`, `docs/<slug>/` | landing site (generated by `docs/build.py`) |
| `PYPI_RELEASE.md` | release checklist; `ghosh-research` name verified free, not published |

## Constraints the repo respects

- No emojis in code or docs.
- Every reported number comes from an actual run with a fixed seed.
- Implementations are original code expressing the papers' ideas; paper text is not copied.
